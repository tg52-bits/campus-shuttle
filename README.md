# Campus Shuttle

## Spatio-Temporal Mobility Database

A PostgreSQL + PostGIS database for analyzing campus shuttle
operations, vehicle movement, occupancy, delays, and cascading
delay propagation.

## Project Objective

The project models campus shuttle operations as a spatio-temporal
mobility system and investigates how database design and query
optimization can support the identification and analysis of
cascading delays.

## Technology Stack

- PostgreSQL
- PostGIS
